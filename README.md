## Como executar o notebook

1. Abra o arquivo no Google Colab (ou em qualquer ambiente Jupyter).
2. Execute as células em ordem sequencial, pelo menu Ambiente de execução, opção Executar tudo, ou célula a célula com Shift + Enter.
3. Vários exercícios pedem dados pelo teclado por meio de `input()`, basta digitar o valor na caixinha exibida abaixo da célula.

## Observações

- O exercício 23 reutiliza a função criada no exercício 22, por isso as células devem ser executadas em ordem.
- O exercício 28 utiliza a biblioteca `matplotlib`, que já vem instalada no Google Colab.
